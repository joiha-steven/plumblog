title: Notes in plain text date: 2026-05-03 tags: writing, tools excerpt:

I keep notes as plain text files in one folder. Search is fast, backups are a copy, and every editor I have ever used can open them.

The only structure is the file name: a date, then a few words. After eight years there are a few thousand files, and finding one still takes a second.

  1. One folder, no subfolders.
  2. Date first, so the list sorts itself.
  3. Links between notes are just file names.
