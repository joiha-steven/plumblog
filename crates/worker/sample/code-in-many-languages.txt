excerpt: Reading a config value and printing a greeting, written the way each language likes it.

A small task makes the shape of a language easy to see. Each example reads a name and prints a greeting.

```sh
#!/usr/bin/env bash
# Greet the user named in $NAME, or the shell user.
name="${NAME:-$USER}"
if [ -n "$name" ]; then
  echo "Hello, $name" | tee -a greet.log
fi
cargo build --release --target wasm32-unknown-unknown
```

```js
// Greets after a short wait; `await` keeps it readable.
const wait = (ms) => new Promise((r) => setTimeout(r, ms));
export async function greet(name = "world") {
  await wait(10);
  return `Hello, ${name}!`.replace(/!+$/g, "!");
}
console.log(await greet(), 3.14, 0xff, null);
```

```ts
interface Person { name: string; age?: number }
type Greeter = (p: Person) => string;
const greet: Greeter = ({ name }) => `Hello, ${name}`;
```

```python
from dataclasses import dataclass

@dataclass
class Person:
    name: str
    age: int = 0

def greet(p: Person) -> str:
    """Return a greeting."""
    return f"Hello, {p.name}" if p.name else "Hello"

print(greet(Person("Ada", 36)), len(range(10)), None, True)
```

```rust
#[derive(Debug, Clone)]
struct Person<'a> {
    name: &'a str,
    age: u32,
}

fn greet(p: &Person<'_>) -> String {
    format!("Hello, {}", p.name)
}

fn main() {
    let ada = Person { name: "Ada", age: 36 };
    println!("{} ({})", greet(&ada), ada.age + 1);
}
```

